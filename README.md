# CampusFlow — Assignment & Submission Management System

A role-based full-stack app for a school/college where **Teachers** create and grade assignments, **Students** submit and track their work, and **Admins** manage the platform. Built for the OnnoRokom Projukti Assistant Software Engineer recruitment project.
